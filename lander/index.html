GonkLander

Land on an unfamiliar machine, run one command, and make it Gonk-compatible.

Install

macOS / Linux
curl -fsSL https://marclevin.me/gonk | bash
Windows (PowerShell)
irm https://marclevin.me/gonk.ps1 | iex
Install and land the dev tools in one go
curl -fsSL https://marclevin.me/gonk | GONK_PROFILE=dev bash

No root, no edits to your shell profile, safe to run again. If gonk is not found afterwards, add export PATH="$HOME/.local/bin:$PATH" to ~/.zshrc or ~/.bashrc.

Equip

gonk doctor
gonk land dev

On a Mac, Gonk installs tools with Homebrew, so install Homebrew first.

Reach home

  1. Install Tailscale and sign in to the tailnet.
  2. Point Gonk at home and connect:
gonk config set home.host gonksystem
gonk config set home.user marc
gonk home status
gonk home shell

gonk home shell --tmux gives a session that survives a dropped connection. Once Tailscale is up, plain ssh marc@gonksystem works too.

Without the website

curl -fsSL https://raw.githubusercontent.com/marclevin/GonkLander/main/lander/install.sh | bash
